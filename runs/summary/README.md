# runs/summary

These files are committed to the repository (the rest of `runs/` is ignored).

| File | Contents |
|---|---|
| `results.json` | Compact summary generated by `python -m charger.summarize`: every evaluation (success rate, Wilson 95% interval, per-stage rates, per-episode outcome), every training run (config and validation curve), and the full-dataset validation summary. |
| `dataset_audit.json` | Audit of the collection: attempts, successes, duplicate counts, stage frame counts, seed splits. |
| `formal_rgb_stages.json` | The stage sidecar of the training dataset (per-episode seeds, stage boundaries, attempts). |
| `formal_rgb_trajectory.json` | Official `trajectory.json` of the training dataset: env kwargs and per-episode `reset_kwargs` needed to reproduce any episode. |
| `old_verify_log.txt` | Kept for provenance: the failure log of the superseded `verify_data` check whose verdict ("rendering corrupts physics") was later disproved. See `EXPERIMENTS.md` section 6. |

Regenerate `results.json` after new evaluations:

```bash
python -m charger.summarize --runs runs --out runs/summary/results.json
```
